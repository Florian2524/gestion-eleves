# Application Full Stack de gestion des élèves

Application web permettant de gérer les élèves, les classes, les inscriptions,
les enseignants, les matières, les notes et les bulletins scolaires.

## Technologies prévues

### Backend

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT
- PostgreSQL
- Maven

### Frontend

- React
- Tailwind CSS
- Axios

### Infrastructure et outils

- Docker Compose
- Git
- GitHub
- JUnit 5
- Mockito
- MockMvc

## Organisation du projet

- `backend` : API REST Spring Boot
- `frontend` : interface React
- `docs/merise` : MCD, MLD et MPD
- `docs/uml` : diagrammes UML
- `docs/scrum` : backlog et rapports de sprint
